# wkil Copilot — Phase 1 Foundations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the copilot's foundation — chat home page, LangGraph agent loop, read-only tools, onboarding interview — so an owner can set up and query their business by chatting.

**Architecture:** New `src/modules/copilot` in the Express monolith: LangGraph `StateGraph` on the existing provider-agnostic `modelRuntime` (new `"copilot"` AiPipeline key), typed UI envelopes over Socket.IO + REST, Prisma persistence. Frontend: new `copilot` route in the Next.js dashboard becomes the default landing; existing pages untouched.

**Tech Stack:** Node/TS/Express, LangChain/LangGraph (PostgresSaver checkpoint), Prisma/PostgreSQL, Socket.IO, vitest · Next.js 15, React Query, socket.io-client, Tailwind, next-intl.

**Spec:** `docs/superpowers/specs/2026-08-23-copilot-chat-design.md`

## Global Constraints

- **Library-first, always** — before writing custom code, check for a well-maintained package / framework feature / existing repo tool; custom code is the last resort with a comment explaining why.
- **Audit from-scratch code** — when touching existing custom code that a library now covers, note it in the plan/PR; switch when low-risk and in-scope; record out-of-scope switches as follow-ups, never silently.
- Two git repos: backend commits in `wkil-fullstack/back-end`, frontend commits in `wkil-fullstack/app`. Commit to the repo you touched.
- Tests: vitest, colocated `*.test.ts`, `globals: false` (import `{ describe, it, expect, vi }` from `"vitest"`). Mock `@config/prisma` with a factory + typed alias; always mock `@utils/logger`. **Never mock `@langchain/*` packages** — consumers mock the runtime module instead (repo convention, see `nodes/callModel.test.ts`).
- IDs are `Int @id @default(autoincrement())`; parse route params with `z.coerce.number().int().positive()`.
- Every new route MUST be documented in `docs/openapi.yaml` and `npm run docs:check` must pass; add the mount assertion to `src/app.routes.test.ts`.
- Every AI entry point: `assertQuotaAvailable(userId, businessProfileId?)` before the run, `recordAiUsage(...)` after.
- i18n: every user-facing string in BOTH `messages/en/...` and `messages/ar/...`; RTL via Tailwind logical properties (`ms-/me-/ps-/pe-`) and `rtl:` variants.
- Frontend has no test runner — verification is `npx tsc --noEmit` + `npm run lint` + the manual QA script in Task 15.
- Follow design tokens (`var(--wk-primary)` etc.) and `cn()` from `@/lib/utils`; framer-motion sparingly.

- **D1:** `src/modules/ai-agent/core/checkpointer.ts` exists (PostgresSaver) but was **never wired** — no graph compiles with it and `setup()` is never called. Task 8 wires it for the copilot graph.
- **D2:** `app/src/types/openapi.generated.ts` is generated by `types:api` but **unused app-wide**. Copilot frontend follows the local-interface service convention. Repo-wide adoption = follow-up.
- **D3:** Owner business-profile update is controller-inline (`business.controller.ts`). Task 7 extracts an owner-scoped service wrapper instead of duplicating.
- **D4:** The website-scrape pipeline lives inside a route handler (`scraping/scrape.ts`). Task 7 extracts `scraping.service.ts → analyzeWebsiteForUser`; route behavior unchanged.
- **D5:** The `Lead` model is a website contact-form capture, NOT business-scoped. The CRM "leads" the spec means are `Customer` rows — `get_leads` maps onto `listCustomers`.

```ts
// src/modules/copilot/copilot.store.ts
import prisma from "@config/prisma";
import type { CopilotConversation, CopilotMessage, CopilotMessageRole } from "@prisma/client";

export async function getOrCreateCopilotConversation(userId: number, locale: string): Promise<CopilotConversation> {
  const existing = await prisma.copilotConversation.findFirst({
    where: { userId }, orderBy: { lastMessageAt: "desc" },
  });
  if (existing) return existing;
  return prisma.copilotConversation.create({ data: { userId, locale } });
}

export async function getCopilotConversationForUser(conversationId: number, userId: number): Promise<CopilotConversation> {
  const conv = await prisma.copilotConversation.findFirst({ where: { id: conversationId, userId } });
  if (!conv) throw new AppError("Copilot conversation not found", 404);
  return conv;
}

export async function appendCopilotMessage(params: {
  conversationId: number; role: CopilotMessageRole; envelope: unknown;
}): Promise<CopilotMessage> {
  const message = await prisma.copilotMessage.create({
    data: { conversationId: params.conversationId, role: params.role, envelope: params.envelope as object },
  });
  await prisma.copilotConversation.update({
    where: { id: params.conversationId }, data: { lastMessageAt: new Date() },
  });
  return message;
}

export async function listCopilotMessages(conversationId: number, limit = 20): Promise<CopilotMessage[]> {
  const rows = await prisma.copilotMessage.findMany({
    where: { conversationId }, orderBy: { createdAt: "desc" }, take: limit,
  });
  return rows.reverse();
}

export async function setCopilotOnboardingStep(conversationId: number, step: string): Promise<void> {
  await prisma.copilotConversation.update({ where: { id: conversationId }, data: { onboardingStep: step } });
}

export async function completeCopilotOnboarding(conversationId: number): Promise<void> {
  await prisma.copilotConversation.update({
    where: { id: conversationId }, data: { kind: "GENERAL", onboardingStep: "done" },
  });
}
```

```ts
export async function streamDecisionOrTool(params: {
  systemInstruction: string;
  contents: AgentContent[];
  tools: AgentToolDefinition[];
  temperature?: number;
  timeoutMs?: number;
  pipeline?: string;
  onTextDelta?: (delta: string) => void;
}): Promise<DecisionOrToolResult> {
  const messages = toLangChainMessages(params.contents, params.systemInstruction);

  const { result: aggregated, model } = await executeWithModelFallback<any>(
    async (tier, abortSignal, ctx) => {
      const llm = createChatModel({
        tier,
        temperature: params.temperature ?? 0.4,
        maxOutputTokens: ctx.defaultMaxOutputTokens ?? undefined,
      }) as any;
      const stream = await llm
        .bindTools(params.tools as any)
        .stream(messages, { signal: abortSignal } as any);
      let final: any;
      for await (const chunk of stream) {
        const delta = contentToText(chunk?.content);
        if (delta) params.onTextDelta?.(delta);
        final = final ? final.concat(chunk) : chunk;
      }
      return final;
    },
    "Copilot.streamDecisionOrTool",
    params.timeoutMs,
    params.pipeline ?? "copilot",
  );

  return {
    toolCalls: readToolCalls(aggregated),
    rawText: contentToText(aggregated?.content),
    usage: readUsage(aggregated),
    modelName: model,
    finishReason: readFinishReason(aggregated),
  };
}
```

```ts
import type { AgentContent, ToolCall } from "@modules/ai-agent/core/agentState";
import type { CopilotEnvelope } from "./copilot.types";

export const CopilotState = Annotation.Root({
  userId: Annotation<number>(),
  conversationId: Annotation<number>(),
  locale: Annotation<"ar" | "en">(),
  mode: Annotation<"onboarding" | "general">(),
  onboardingStep: Annotation<string | null>({ value: (_, u) => u, default: () => null }),
  contents: Annotation<AgentContent[]>({ value: (_, u) => u, default: () => [] }),
  toolCalls: Annotation<ToolCall[]>({ value: (_, u) => u, default: () => [] }),
  toolRounds: Annotation<number>({ value: (_, u) => u, default: () => 0 }),
  toolResults: Annotation<{ name: string; result: unknown }[]>({ value: (_, u) => u, default: () => [] }),
  rawText: Annotation<string>({ value: (_, u) => u, default: () => "" }),
  envelopes: Annotation<CopilotEnvelope[]>({ value: (_, u) => u, default: () => [] }),
  usage: Annotation<{ promptTokens: number; completionTokens: number }>({
    value: (prev, u) => ({ promptTokens: prev.promptTokens + u.promptTokens, completionTokens: prev.completionTokens + u.completionTokens }),
    default: () => ({ promptTokens: 0, completionTokens: 0 }),
  }),
  modelName: Annotation<string>({ value: (_, u) => u, default: () => "" }),
});
```

`copilot.graph.ts` — nodes (each `(state: CopilotStateType) => Promise<Partial<CopilotStateType>>`, matching `agentGraphV2` conventions):

- `loadContext`: `getCopilotConversationForUser` + `listCopilotMessages(id, 20)`; map stored messages to `AgentContent` (`USER` → `{ role: "user", content: <text from envelope> }`; `ASSISTANT` → `{ role: "assistant", content: <concat of text envelopes> }`); append the new user text; build system prompt; return `{ contents, mode, onboardingStep }` (mode from `conv.kind === "ONBOARDING"`).
- `callModel`: build `AgentToolDefinition[]` (`{ name, description, schema }` from `copilotTools`, filtered to onboarding tools when `mode === "onboarding"`); call `streamDecisionOrTool({ pipeline: "copilot", systemInstruction, contents: state.contents, tools, onTextDelta: (d) => emitToCopilot(state.userId, "copilot:delta", { conversationId: state.conversationId, delta: d }) })`; return `{ toolCalls, rawText, usage, modelName }`.
- `executeTools`: for each `toolCall` — `findCopilotTool`, `tool.schema.parse(args)` (on zod error, tool result = `{ error: "Invalid arguments" }`), `handler(args, { userId, conversationId, locale, onProgress: (m) => emitToCopilot(state.userId, "copilot:message", { conversationId, envelopes: [{ type: "progress", message: m }] }) })`; append `{ role: "tool", toolCallId, toolName, toolResult }` to `contents`, collect `toolResults`, `toolRounds: state.toolRounds + 1`.

```ts
// src/modules/copilot/copilot.service.ts
import { AppError } from "@middlewares/errorHandler.middleware";
import { logger } from "@utils/logger";
import { assertQuotaAvailable, recordAiUsage } from "@modules/billing/billing.service";
import { emitToCopilot } from "@modules/realtime/socket";
import { runCopilotGraph } from "./copilot.graph";
import { appendCopilotMessage, getCopilotConversationForUser, getOrCreateCopilotConversation } from "./copilot.store";
import type { CopilotEnvelope } from "./copilot.types";

const ERROR_TEXT: Record<"ar" | "en", string> = {
  ar: "الخدمة مش متاحة دلوقتي، جرب تاني بعد شوية.",
  en: "The service is unavailable right now — please try again shortly.",
};

export async function runCopilotTurn(params: {
  userId: number; text: string; locale: "ar" | "en"; conversationId?: number;
}): Promise<{ conversationId: number; envelopes: CopilotEnvelope[] }> {
  const conv = params.conversationId
    ? await getCopilotConversationForUser(params.conversationId, params.userId)
    : await getOrCreateCopilotConversation(params.userId, params.locale);

  await assertQuotaAvailable(params.userId);
  await appendCopilotMessage({ conversationId: conv.id, role: "USER", envelope: { type: "text", text: params.text } });

  let envelopes: CopilotEnvelope[];
  try {
    const out = await runCopilotGraph({ conversationId: conv.id, userId: params.userId, locale: params.locale, text: params.text });
    envelopes = out.envelopes;
    await recordAiUsage({
      userId: params.userId, modelName: out.modelName, operation: "copilot_chat",
      conversationId: String(conv.id), promptTokens: out.usage.promptTokens, completionTokens: out.usage.completionTokens,
    });
  } catch (error: any) {
    logger.error("copilot.turn_failed", { conversationId: conv.id, error: error?.message });
    envelopes = [{ type: "error", message: ERROR_TEXT[params.locale], retryable: true }];
  }

  await appendCopilotMessage({ conversationId: conv.id, role: "ASSISTANT", envelope: { envelopes } });
  emitToCopilot(params.userId, "copilot:message", { conversationId: conv.id, envelopes });
  return { conversationId: conv.id, envelopes };
}
```

```ts
import { fetchWithAuth } from "@/services/auth-api";
import { COPILOT_API } from "./config";

export type CopilotEnvelope =
  | { type: "text"; text: string }
  | { type: "stat-grid"; items: { label: string; value: string | number; hint?: string }[] }
  | { type: "lead-list"; leads: { id: number; name: string; channel?: string | null; interest?: string | null; createdAt?: string }[]; total?: number }
  | { type: "conversation-list"; conversations: { id: number; customerName: string; channel?: string | null; handoffCategory?: string | null; preview?: string | null }[] }
  | { type: "progress"; message: string }
  | { type: "link-card"; title: string; description?: string; href: string; cta: string }
  | { type: "error"; message: string; retryable: boolean };

export interface CopilotConversation { id: number; kind: "ONBOARDING" | "GENERAL"; locale: string; lastMessageAt: string; }
export interface CopilotMessage { id: number; role: "USER" | "ASSISTANT" | "SYSTEM"; envelope: any; createdAt: string; }

class CopilotService {
  async getConversation(signal?: AbortSignal): Promise<CopilotConversation> {
    const res = await fetchWithAuth<{ data: CopilotConversation }>(COPILOT_API.CONVERSATION, { signal });
    return res.data;
  }
  async getMessages(limit = 50, signal?: AbortSignal): Promise<CopilotMessage[]> {
    const res = await fetchWithAuth<{ data: CopilotMessage[] }>(`${COPILOT_API.MESSAGES}?limit=${limit}`, { signal });
    return res.data;
  }
  async postMessage(text: string): Promise<{ conversationId: number; envelopes: CopilotEnvelope[] }> {
    const res = await fetchWithAuth<{ data: { conversationId: number; envelopes: CopilotEnvelope[] } }>(
      COPILOT_API.MESSAGES, { method: "POST", body: JSON.stringify({ text }) });
    return res.data;
  }
}
```

```ts
"use client";
import { useEffect } from "react";
import { useQueryClient } from "@tanstack/react-query";
import { useAuth } from "@/contexts/AuthContext";
import { useSocket } from "@/components/providers/SocketProvider";
import { COPILOT_KEYS } from "./copilot.keys";
import type { CopilotEnvelope, CopilotMessage } from "@/lib/copilot-api";

export function useCopilotSocket(params: {
  conversationId?: number;
  onDelta: (delta: string) => void;
  onStreamEnd: () => void;
}) {
  const { socket } = useSocket();
  const { user } = useAuth();
  const queryClient = useQueryClient();
  const { conversationId, onDelta, onStreamEnd } = params;

  useEffect(() => {
    if (!socket || !user?.id) return;
    socket.emit("join_copilot", user.id);

    const handleDelta = (p: { conversationId: number; delta: string }) => {
      if (p.conversationId === conversationId) onDelta(p.delta);
    };
    const handleMessage = (p: { conversationId: number; envelopes: CopilotEnvelope[] }) => {
      if (p.conversationId !== conversationId) return;
      onStreamEnd();
      queryClient.invalidateQueries({ queryKey: COPILOT_KEYS.messages() });
    };

    socket.on("copilot:delta", handleDelta);
    socket.on("copilot:message", handleMessage);
    return () => { socket.off("copilot:delta", handleDelta); socket.off("copilot:message", handleMessage); };
  }, [socket, user?.id, conversationId, onDelta, onStreamEnd, queryClient]);
}
```

```tsx
import { useCallback, useState } from "react";
import { useTranslations } from "next-intl";
import { copilotService } from "@/lib/copilot-api";
import { useCopilotConversation } from "@/hooks/copilot/useCopilotConversation";
import { useCopilotSocket } from "@/hooks/copilot/useCopilotSocket";
import { MessageStream } from "./MessageStream";
import { Composer } from "./Composer";
import { QuickReplies } from "./QuickReplies";

export function CopilotShell() {
  const t = useTranslations("copilot");
  const { conversation, messages, isLoading } = useCopilotConversation();
  const [streamingText, setStreamingText] = useState("");
  const [pending, setPending] = useState(false);

  const onDelta = useCallback((d: string) => setStreamingText((prev) => prev + d), []);
  const onStreamEnd = useCallback(() => { setStreamingText(""); setPending(false); }, []);
  useCopilotSocket({ conversationId: conversation?.id, onDelta, onStreamEnd });

  const send = async (text: string) => {
    setPending(true);
    try {
      await copilotService.postMessage(text);   // REST fallback: response arrives here
      onStreamEnd();                             // if socket delivered first, this is a no-op
    } catch {
      setPending(false);
      onStreamEnd();
    }
  };

  return (
    <div className="flex h-full flex-col">
      <MessageStream messages={messages ?? []} streamingText={streamingText} isLoading={isLoading} />
      {pending && !streamingText && <ThinkingIndicator label={t("thinking")} />}
      <QuickReplies onPick={send} disabled={pending} />
      <Composer onSend={send} disabled={pending} placeholder={t("placeholder")} />
    </div>
  );
}
```
